# 口语题库使用说明

转换日期：2026-10-23。原始PDF保持不变，三份合计564页。

## 文件入口

- [口语练习题库](口语练习题库.md)：默认出题入口，按Part及话题整理，不含参考答案；合并跨页折行。
- [逐页纯题目](口语题库-纯题目-逐页.md)：72页，按原PDF物理页码保存正文，用于核对原文。
- [Part 1题目及参考答案](口语Part1-题目与参考答案-逐页.md)：136页，保留中文翻译。
- [Part 2及Part 3题目与参考答案](口语Part2及Part3-题目与参考答案-逐页.md)：356页，保留中文翻译。
- [机器可读题目索引](练习题目索引.json)：含题目ID、话题、分组和起止页码，用于选题及记录。
- [转换核对报告](转换核对报告.json)：页数、校验值、数量及已发现疑点。

## 抽取结果

Part 1共31个话题、195个问题；Part 2共54张题卡，关联Part 3共288个问题。共537条题目/题卡原始记录，其中1条Part 3原文仅为陈述句，已标记暂停选题。学生版、工作版保留分组；相似主题不自动合并。

## 校对范围

已确认三份PDF每页均可提取文字，无空页或替换乱码字符；逐页Markdown保留全部提取文本。结构化检查覆盖题目ID唯一、问题编号连续、无未归属正文、Part 2提示点存在及跨页衔接。视觉抽查6页，不代表逐字校对全部原文。

原文存在语法疑点和可能不完整的题目，已发现项在练习题库和JSON中标记。逐页版原文保持不变；结构化版仅去除一处分组分隔线。出题前仍逐题核对，不自动将材料标为官方题库或声称题目覆盖全部考试。

## 在项目中使用

先依据已学表达和待复习内容，从纯题目索引选匹配问题；每次记录题目ID及来源页码。可从题目中拆出造句或短答任务，拆题或改写需注明「基于原题的练习」，不冒充原题。默认先让用户回答，再按需查参考答案；参考答案不是唯一标准，也不作为用户产出。

当前两条表达可关联：S26-P3-N19-Q01（自律与学习新技能，纯题目PDF第36页）及同话题其他追问。仅建立候选联系，不标记为已练，当前待完成的 rewarding 重写保持不变。

当前只导入口语题库，尚未收到写作题库；不能把口语题标成IELTS写作真题。所有口语题均以文字作答，适合练习措辞、组织和搭配。

转换脚本：项目根目录 `scripts/convert_speaking_pdfs.py`，使用带pypdf的Python运行。脚本可重新生成转换文件；不要在自动生成文件内保存个人学习状态，个人进度仍写入表达库和学习日志。
